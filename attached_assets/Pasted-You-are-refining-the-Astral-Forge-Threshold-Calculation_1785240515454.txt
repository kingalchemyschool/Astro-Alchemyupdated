You are refining the Astral Forge Threshold Calculation System.

The thresholds are not separate planetary placements. They are derived synthesis points that reveal how multiple planetary functions combine within the existing blueprint.

Astral Forge does not create a blueprint. It interprets and refines the blueprint already encoded within the natal chart.

The purpose of the thresholds is to identify the transformation that occurs when planetary functions interact.

Each threshold should answer:
"How does this blueprint transform one function into another?"

The app should calculate thresholds by combining the planetary functions that create each synthesis point.

Do not calculate thresholds as standalone planets.
Do not assign thresholds based on a single placement.
Do not interpret thresholds as personality traits.

Each threshold is calculated from:
1. The strength of each planetary function
2. The relationship between the planetary functions
3. The sign expression of each planet
4. The house placement of each planet
5. The aspects modifying each planet
6. The interaction between the paired functions

POINT 3 — IMPACT THRESHOLD

PLANETARY INPUTS:

♂ Mars + ♇ Pluto
FUNCTION:
Magnitude + Direction

☿ Mercury + ♅ Uranus
FUNCTION:
Translation + Ingenuity

PURPOSE:

The Impact Threshold reveals how the blueprint converts intelligence and force into external consequence.

Mars and Pluto determine:
- magnitude of force
- intensity of action
- depth of transformation
- direction of applied energy

Mercury and Uranus determine:
- translation of information
- ability to identify patterns
- innovative thinking
- creation of unique approaches

The Impact Threshold answers:

"How does this blueprint turn unique intelligence into meaningful external consequence?"

The interpretation should explain:
- how force is generated
- how force is directed
- how intelligence is translated into strategy
- how innovation changes the method of execution
- what type of impact naturally results

CALCULATION:

Impact Score =
(Mars Function Score + Pluto Modifier)
+
(Mercury Function Score + Uranus Modifier)

Mars Score evaluates:
- initiation capacity
- drive
- execution style

Pluto Modifier evaluates:
- magnitude
- transformational depth
- intensity

Mercury Score evaluates:
- translation ability
- communication
- organization of information

Uranus Modifier evaluates:
- ingenuity
- originality
- breakthrough potential

Aspect modifiers determine whether these functions flow together or require refinement.

Output:
A description of HOW this blueprint creates impact.
