---
name: Daily Forge activation language
description: Writing rule for transit activation cards and generated report language
---

Daily Forge activation copy should describe the lived function being engaged—such as instinctive responses, boundaries, purpose, or deep transformation—and explain how the aspect changes that contact. Avoid bare labels like “emotional life” or “values.”

**Why:** One-word planet keywords make otherwise detailed transit reports feel generic and force the reader to translate the meaning themselves.

**How to apply:** Use concrete transit and natal function descriptions with aspect-specific verbs for conjunction, trine, sextile, square, and opposition. Version report caches when generated wording changes.
