name: Daily Forge feed structure
description: Reference-driven hierarchy and interaction model for the Daily Forge You surface
---

The Daily Forge You surface has exactly two subpages: Daily Forge and Today’s Transit. Daily Forge uses the restored ForgeReport format with Moon/celestial-field blocks disabled; Today’s Transit contains one unified non-Moon transit list. Do not add life-area tabs or transit subsections. Every transit uses the same expandable card format; timing is an inline label, not a subsection. Cards show placement, natal contact, house, orb, meaning, and daily application. World order is chart, Moon, current planet cards, then world transits.

**Why:** The mobile reference prioritizes fast scanning and progressive disclosure. Personal and world sky information must remain distinct; repeating Moon content or splitting personal transits into separate blocks obscures the natal-house transit reading.

**How to apply:** Keep the You-specific composition in its focused feed component. Render all qualifying non-Moon aspects in Today’s Transit and add detail through the shared expandable card. Reserve the Moon, world chart, current planet placements, and world transit list for World; reserve full natal charts for Natal and calendar contexts.
