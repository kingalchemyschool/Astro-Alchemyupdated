---
name: Report prose variation
description: Generated reports should reinforce recurring concepts through varied, context-sensitive language rather than repeated sentence templates.
---

Recurring ideas may remain conceptually consistent, but their wording should vary by aspect, planet pairing, or report context. Exact sentence repeats within a generated report should be removed during assembly.

**Why:** Fixed explanatory closings became conspicuous when several Daily Forge aspects shared the same relationship type, making the report feel templated instead of personally interpreted.

**How to apply:** Add deterministic phrasing variants for repeated concepts and run assembled paragraph arrays through sentence-level exact-duplicate filtering. Preserve intentional labels, formulas, and section headings.
